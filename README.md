# 🌤️ WeatherSphere - AI-Powered Weather Intelligence

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Python 3.12](https://img.shields.io/badge/Python-3.12-blue.svg)](https://python.org)

> Multi-agent weather intelligence platform that forecasts patterns, classifies alerts, and monitors air quality using MiMo V2.5 AI models.

## 🤖 AI Agents

| Agent | Model | Runs | Tokens/Day |
|-------|-------|------|------------|
| Weather Predictor | MiMo V2.5 Pro | 2,340 | 14.2M |
| Alert Classifier | MiMo V2.5 | 1,560 | 6.8M |
| Climate Analyst | MiMo V2.5 Pro | 890 | 8.4M |
| AQI Monitor | MiMo V2.5 | 1,780 | 5.1M |

## 🚀 Quick Start

```bash
pip install fastapi uvicorn jinja2
python app.py
```
